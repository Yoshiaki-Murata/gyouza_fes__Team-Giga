## 3. 画面・ページ要件（静的HTMLからの変更点）
    既存の静的ファイルをどのようにシステム化するか、また新規で作成する画面を整理します。

* **既存ページの改修**: 
    * `contact.html` → お問い合わせフォームの動的化（バリデーション追加など）
    * `index.html` → ヘッダー、フッターを別ファイル(php)で統一
* **新規作成するページ**:
    * 管理者ログイン画面
    * 管理者ダッシュボード（お問い合わせ一覧、各種操作ボタン・リンクなど）
    * お知らせ投稿ページ

## 4. データ要件（データベース設計の素案）
    システムで保存・管理するデータを洗い出します。
    ※いったん全部物理削除

* **お問い合わせデータ**:
    id、氏名、メールアドレス、電話番号、本文、送信日時、対応ステータス
* **管理者データ**: 
    ID、ユーザー名、パスワードのハッシュ値
* **お知らせ更新機能・表示**: 
    id、件名、日時、本文
* **メニュー一覧**: 
    id、店名、個数、値段、商品詳細、店舗詳細

## 5. 技術・非機能要件
* **開発言語・環境**: 
    PHP( Version 8.2.12),MySQL(mysqlnd 8.2.12),Apache(Apache 2.0 Handler)
* **セキュリティ対策**: 
    * SQLインジェクション対策
        →bindpramを使う。
    * クロスサイトスクリプティング（XSS）対策
    　　→form入力欄はhttpspecialcharsを使う。
    * 管理画面の認証（URL直叩きの防止）
        セッションを使ったログイン状態判別（ログインしていないと入れないように）
